# 🚀 Quick Start

Get MDMCP running in minutes.

## Prerequisites
- Node.js >= 18.0.0
- npm

## Installation
```bash
git clone <repository-url>
cd modelmarkdownprotocol
npm install
npm run install:all
```

## Start Development
```bash
npm run dev
```

Frontend: `http://localhost:3000`
MCP Server: Auto-configured port

## CLI Usage
```bash
npm install mdmcp -g
mdmcp-server    # Start MCP server
mdmcp-frontend  # Start frontend
```
